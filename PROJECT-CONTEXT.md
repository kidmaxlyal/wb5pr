## Последние пожелания пользователя
- Светлый фон сайта, кислотно-розовые акценты.
- Яркие сюрреалистичные киберпанк-самокаты без фона.
- Собственный логотип; меньше шаблонных декоративных элементов.
- Заметный моушн-дизайн первого экрана и прокрутка самокатов.
- Переработанная сетка, Flexbox и шрифт; последняя версия использует Barlow Condensed.
- Современные стеклянные кнопки «Найти самокат» и «Наверх», без стрелок.
- Нумерация 1, 2, 3, а не 01, 02, 03.

## Функциональные требования
HTML/CSS/ванильный JS, ES-модули main.js, data.js, storage.js; без сборки и серверной части.
Общие данные для схемы и списка, уникальные id, восемь объектов, два изначально заняты.
Синхронные фильтры, выбор, расчёт, подтверждение без дублей, отмена и localStorage.
Обработка неверного ввода, повреждённого хранилища и ошибок записи.
Доступность с клавиатуры, сохранение понятного фокуса, мобильная версия, текстовые статусы.
Сброс только своих броней с подтверждением. Видимое пояснение учебного режима.
Для сдачи нужны публичный сайт и репозиторий.
