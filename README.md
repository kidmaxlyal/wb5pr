# НА КОЛЁСАХ

Учебное демо бронирования городских самокатов. В проекте используются HTML, CSS и JavaScript ES-модули; сборка и серверная часть не нужны.

## Запуск

Открой папку проекта в VS Code и запусти `index.html` через расширение Live Server. Страницу нужно открыть по HTTP, а не двойным щелчком по файлу: браузеру нужен сервер для загрузки ES-модулей.

## Что работает

- Выбор одного из восьми самокатов на схеме станции или в списке.
- Фильтры по модели и цене за час.
- Расчёт стоимости от одного до двенадцати часов.
- Создание и отмена брони.
- Сохранение броней в `localStorage` этого браузера.
- Прозрачные киберпанк-рендеры трёх моделей лежат в `assets/`.
- SVG-знак бренда находится в `assets/logo.svg`.
- Лента самокатов листается по горизонтали; элементы появляются при прокрутке, а изображения плавно двигаются. Движение отключается системной настройкой «уменьшить движение».

Это учебный пример: брони не отправляются на сервер, оплата и реальная аренда не оформляются. Цены и характеристики демонстрационные.
