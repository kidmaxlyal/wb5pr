# НА КОЛЁСАХ

Учебный сайт бронирования электросамокатов в Санкт-Петербурге. Выбери самокат на карте или в каталоге, укажи время аренды и посмотри стоимость перед подтверждением.

## Что есть на сайте

- Интерактивная карта центра Санкт-Петербурга на Leaflet и [OpenStreetMap](https://www.openstreetmap.org/copyright). Восемь демонстрационных самокатов, два из которых изначально заняты.
- Каталог с фильтрами по модели и максимальной цене за час.
- Расчёт стоимости аренды на срок от 1 до 12 часов, создание и отмена брони. Брони сохраняются в `localStorage` текущего браузера.
- Анимированная витрина трёх моделей, киберпанк-иллюстрации самокатов и пиксельный шрифт Pixelify Sans. Вёрстка адаптируется под телефон.

Расположение самокатов, цены и характеристики демонстрационные. Сайт не оформляет реальные поездки и не принимает оплату.

## Как запустить

Открой папку проекта в VS Code и запусти `index.html` через расширение Live Server. Для ES-модулей нужен локальный HTTP-сервер. Карта и шрифт загружаются через интернет.

Проект написан на HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются. Папка `dist/` содержит файлы для размещения на статическом хостинге.
